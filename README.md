# OnlineTool.me

OnlineTool.me is a calculator-first collection of free online tools built with Astro.

**Live website:** [https://onlinetool.me/](https://onlinetool.me/)

**Sitemap:** [https://onlinetool.me/sitemap-index.xml](https://onlinetool.me/sitemap-index.xml)

## Local development

```sh
npm install
npm run dev
```

## Build and test

```sh
npm run test
npm run build
```

Calculator pages must follow the requirements in [`docs/CALCULATOR_PAGE_STANDARD.md`](docs/CALCULATOR_PAGE_STANDARD.md).
