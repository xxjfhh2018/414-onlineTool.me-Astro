# OnlineTool.me Brand Identity

## Brand idea

OnlineTool.me uses an unmistakable calculator as its primary mark. The display and six-key layout communicate the site's calculator-first positioning before the wordmark is read.

## Name and wordmark

- Always write the brand name as `OnlineTool.me`.
- Use the horizontal logo when space permits.
- Use the calculator mark alone for favicons, avatars, app icons, and compact navigation.
- Do not place a slogan inside the primary logo lockup.

## Colors

| Role | Hex |
| --- | --- |
| Primary teal | `#0F766E` |
| Interactive teal | `#0D9488` |
| Mint highlight | `#5EEAD4` |
| Pale display | `#CCFBF1` |
| Ink | `#111827` |
| Dark background | `#0F0F11` |
| White | `#FFFFFF` |

## Minimum size and spacing

- Use the dedicated favicon assets below 32 px.
- Do not display the horizontal logo below 140 px wide.
- Keep clear space around the mark equal to at least one calculator key diameter.
- Do not stretch, rotate, recolor individual keys, add shadows, or place the mark on a low-contrast background.
